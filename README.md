One sentence, at most 200 characters, that makes a small everyday moment strange and new — for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty. The program writes the sentence to `/output/entry.txt`:

> My phone's autocorrect finished my sentence with a word I have never typed, and for a moment I wondered who else lives in my keyboard.

The angle is the surprise: autocorrect, the invisible helper, finishing a sentence with a word its owner never typed — as if someone else lived in the keyboard. Grounded in a moment everyone knows, landed in a single read.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt` (UTF-8, 1–200 characters) and prints it. Deterministic: the same sentence on every run, no network, no clock, no randomness.
